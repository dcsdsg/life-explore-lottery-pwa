# 城市旅行任务表 · 16城扩展版 v1.1

这是原城市探索 PWA 内的独立页面 `travel.html`。北京30条、苏州16条、秦皇岛6条细分任务仍在原页面，编号与个人记录未迁移。原生活探索抽签机也未改动。

## 内容边界

首辑十城保留，新增家乡湛江、佛山、广州、武汉、深圳、长沙。共16城、96个代表或支线地点、48条可选认城线索、33个阅读入口、5份内置古诗/节选。按文化辨识度、地域差异与旅行可安排性编辑，不是客观或官方旅游排名。每城一份总任务，包含六个代表或可选地点、三条认识线索、两天取舍与三天主线、阅读和来源。新城快捷入口在悬赏标题下；湛江另有家乡标记。

湛江主线将赤坎、霞山与雷州分段，雷州单独一天，硇洲为另一天可选支线；佛山将禅城与顺德分开；广州区分王墓和王宫展区；武汉以三镇地理入门并注明现有黄鹤楼为现代重建；深圳写明2026年改革史展闭展线索、大鹏独立一日；长沙区分考古原址、现有纪念空间与文学文本，不依赖大学自由入校。

不要求把所有地点、线索勾满才算完成。点击“完成这座城”由自己决定；撤销完成仍保留到访、线索与手记。点阅读、导航或展开地点不会写入进度。

预算只估算成人门票和当地交通，不含跨城交通、住宿、餐饮，付费支线、表演和包车另算。时间不是实时导航；到达与离开城市的半天不算完整游玩日。路线与问题是编辑建议，不是地方政府的官方推荐路线。

历史资料优先政府、地方志、场馆与世界遗产来源。政府规划PDF、地方志目录和名录仅标作线索入口，不声称逐页读完。诗文与史实分开：乌衣巷不是保存原样的六朝街区，现存城墙不等于唐城墙，古都遗址保护展示不等于古代原楼，小说不是地方史。

原文入口明确区分：古典原文 / 节选、地点历史资料、作品相关解读。现代作品不内置未经授权的全文。《致橡树》入口是中国作家网相关解读，不能标为诗歌全文。

## 个人数据与备份

- 城市旅行独立保存键保持为：`city-travel-quests:state:v1`。
- 备份：`app: city-travel-quests`，`version: 1`，含城市状态、地点到访、认城线索、6000字以内手记、完成时间。
- 原探索键：`city-exploration-quests:state:v1`，本页不读写它。抽签机数据也不读写。
- 清空只移除本页自己的键，不调用 `localStorage.clear()`。
- 恢复前验证文件类型、城市 / 地点编号、布尔值、长度和完成日期；恢复是替换，不是合并。先导出当前备份。
- 读取坏记录时停止保存和导出，避免把空状态覆盖原数据；由用户选择恢复有效备份或确认清空。
- 原十城v1备份继续接受；原城市与地点编号、三条线索顺序不变。缺少的新城初始化为未计划。恢复仍会替换当前记录，先导出，不悄悄合并。
- 数据只在当前浏览器 / 安装环境。清理浏览器、换手机或卸载可能丢失；没有账号、服务器、同步或会员依赖。

## 离线与安装

共用 `manifest.webmanifest` 和当前探索 PWA，不产生第二个安装身份。苹果使用 Safari 分享 → 添加到主屏幕；安卓浏览器安装。原首页顶部进入“城市旅行 · 16城”。

`service-worker.js` 的独立探索缓存 v6 包含探索、旅行及京西双寺行程页面、脚本、样式、图标和说明。离线导航先匹配请求的页面（忽略城市查询参数），不能把 `travel.html?city=wuhan` 或 `temple-day.html` 退回原探索首页。外部阅读、地图导航与票务不会缓存，也不会自动上传手记。原抽签机缓存不应被清除。

首次联网准备缓存后，断网刷新两页与一个城市深链接测试。自动浏览器测试不能代替真实 iPhone 安装、Safari 权限和系统清理行为的验证。

## 修改内容

1. `travel-data.js`：`TRAVEL_SOURCES` 集中放可靠来源，`TRAVEL_CITIES` 每个对象就是一份总任务。
2. 保留已有城市 `id`、地点 `id` 和三条认城线索的顺序，它们绑定个人数据。新增地点放在原列表之后；改变备份结构先做明确迁移，不悄悄改版本。
3. 每城保持“为什么这些地方能共同解释城市”，不要只堆景点介绍。远郊单独一天，短途提供取舍，日常和休息保留。
4. 所有阅读与资料入口用HTTPS，明确“全文 / 节选 / 解读 / 地点资料”。不要把图书购买页当作全文页。
5. 预约、票价、交通、花期与船班不硬编码成保证；将核实日期、估算和出发前确认写清楚。
6. 新增本地资源必须加入离线 `FILES`，同时增加缓存版本，并更新 `travel.js` 的离线准备版本检查；只删除本PWA旧缓存。

## 验收与发布

使用 Node 与本机 Chrome / Playwright，在仓库的 `city-quests` 目录运行：

```
node scripts/check.cjs
node scripts/check-travel.cjs
node scripts/verify-publication.cjs
node scripts/verify-travel.cjs
```

后两项在发布副本的完整仓库中运行，在临时浏览器里模拟 GitHub Pages 路径，不读取用户日常浏览器记录；本地源码目录不附这两个依赖完整仓库的脚本。环境缺 Playwright 时需配置已安装的模块路径；不为测试清除用户数据。详细结果见同目录的 `十城旅行验收报告.md`。
