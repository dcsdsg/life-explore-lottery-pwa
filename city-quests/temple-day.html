02 / 时间是这次任务的资源

推荐走法：先戒台寺，再潭柘寺

把上午留给戒台寺，午前转场，下午在潭柘寺留够两小时。以下为编辑安排，不是导航实测；国庆堵车、候车和排队会把时间推后。

  1. 06:00–06:15

    从贸大出发

    从合适校门到惠新西街南口，10号线沿安贞门、牡丹园方向至六里桥，换9号线往国家图书馆方向一站到六里桥东。校门到站和出站找车均需时间；这一段暂按75–100分钟留余量，争取7:40前到上车点，按早上导航再提前。

  2. 07:40前争取到 / 08:00发车

    乘通游专线21，去戒台寺景区

    提前找准上车点，向司机确认戒台寺下车及返程。六里桥东公告发车8:00、9:00；推荐第一班。山路段暂留90–135分钟，不保证具体到达时刻。若9:00才出发，两寺深读会明显变紧。

  3. 到达后90–120分钟

    戒台寺：戒坛 + 一棵名松

    以戒坛开放情况为先，再选抱塔松、九龙松或实际可看的保护树，不要求逐棵“十大名松”全打卡。最晚11:45左右启动转场；到达晚就缩减支线。

    看现场任务 ↓
  4. 约11:30–12:30

    简餐与打车转场

    带简餐，不依赖斋饭必定供应。导航目的地选“潭柘寺景区游客入口”，两寺之间用正规出租车/网约车，候车与车程合计先留45–75分钟。车费先留60–100元/车，仅为预算占位，不是已查询报价。

    不要从寺后找野路翻山，也不要照1934年的游记复走后门、古洞路线。若车叫不到，不把“走山路替代”当保底。

  5. 约12:30–14:30

    潭柘寺：主轴、屋顶、古树

    以实际开放的主轴殿堂和古树庭院为主；入口先问出口到公交上车点需多久。若13:00才入园，删去支线，只做“一座殿 + 一株树 + 一段文字”。不要为15:00返城车在台阶上奔跑。

    看现场任务 ↓
  6. 14:30开始出园 / 15:00返城参考

    潭柘寺乘专线回六里桥东，再返贸大

    至少留20–30分钟找站、排队。公告中潭柘寺回六里桥东12:00、15:00；末班、是否发车和上车位置早上即确认。返程公交、地铁及步行先留约3–4小时，18:00–19:00回校只是计划范围，不是保证。

    错过或停运时，按实时导航查931路等回城区路线及末班；也可正规打车到可接续的地铁站。未核验常规公交末班，不提供“肯定赶得上”的时间。

想全程公交、不打车？先看这处时刻冲突

公告列戒台寺→潭柘寺9:30、14:30，潭柘寺→六里桥东12:00、15:00。早班进城出发后很难完成戒台寺深读再赶9:30；14:30转场后又赶不上15:00回城并游览潭柘寺。所以不能把这几个发车时间拼成“全天随到随走”。

可按当天导航换乘普通公交，接受更长候车并另查返程末班；若不愿打车或时间晚，宁可只深读一寺。常规入口参考：戒台寺可从S1石厂换948/M44，潭柘寺有931路；这些是线路线索，不是两寺之间的已核验直达接驳。

费用怎么留

成人门票参考：戒台寺45 + 潭柘寺50 = 95元。潭柘寺参观页列全日制大学生25元；戒台寺有学生优惠，金额先问售票处，不预先替你扣减。

市内公交地铁35–50 + 转场60–100/车 + 简餐20–35。按独自出行：成人合计约210–280元；大学生先按戒台45、潭柘25保守留185–255元。若两人同行且车费分摊，个人费用可降低。

不是实时售票/打车报价，不含香火、购物、额外活动和全程往返包车。专线用正常刷卡/刷码优惠，不是学生证免票。

背包与礼仪

身份证、有效学生证、充电宝、水约1升、简餐、薄外套、防滑鞋。今晚联网打开本页，确认“离线正文已准备”，再试一次飞行模式复开。

不踩门槛、不碰造像与文物；殿内拍摄先询问，禁拍就不拍，不开闪光。古树不抱、不摇、不刻字、不越保护栏。尊重正在进行的宗教活动，文化参观不以买香、捐款或求签为完成条件。

止损规则：景区闭园/山区预警就取消；11:45仍迟迟不能转场，优先保住已在的一寺；13:00后到潭柘寺就减支线；不清楚末班时，先解决返程再继续游览。

03 / 第一份悬赏

戒台寺：传统不是“古老”两个字

引子：一座寺为什么以“戒台”为名？一棵看似自然长成的松，背后又有多少人的维护？

先认识：戒坛做什么

戒坛与佛教受戒、传戒有关，不是抽签台。“授戒”是进入修行身份和纪律体系的重要仪式线索。把“戒台/戒坛”的名字与建筑用途联系起来，比记一个“天下第一”的宣传称号更有意义。

不同网页对隋、唐始建说法不一，本次不硬记某一年；寺院源流、辽以后戒坛传统与现存建筑，分层阅读。具体年代以现场文物说明和碑记核对。

再认识：古树也是被照顾的生命

区文旅局2025年资料登记古树109株，其中一级44株、二级65株，并说明复壮调查与日常养护。看一株树上的支撑、栏杆与保护牌，你看到的不只是形态，也是今天保护传统的工作。

数字是该次登记资料，不是我今天现场重数的结果；树龄采用保护牌，不拿民间故事代替。

  1. 认用途：在开放戒坛区域读一块说明，写下“这个空间用来做什么”。若关闭，读外部说明，不越界。
  2. 认一株松：任选实际开放区域一棵，拍保护牌和全貌（允许时），记名称、树种、树冠与支撑。别因为“活动松”的名字去摇树。
  3. 做一份四行档案：我看到的 / 牌上写的 / 我推测的 / 保护它的人在做什么。没有证据的内容放在推测栏。
  4. 带回问题：如果没有复壮、修缮与日常管理，这种“千年景观”还能自然持续吗？

04 / 第二份悬赏

潭柘寺：把源流、遗存与传说分开

引子：一座寺院的年龄、眼前建筑的年龄、一株树的年龄，是同一个时间吗？

寺院源流 ≠ 所有建筑同龄

寺院传统追溯至晋代；今天参观的是多次营建后的建筑群，旅游资料说明其明清风貌。不能把每座殿都说成“西晋原物”。主轴依山升高，用身体感受院落、台阶和殿堂怎样组织视线。

先从山门、天王殿、大雄宝殿等实际开放部分观察，再决定是否走支线；不保证每座殿能进。

树木、屋顶与故事

到大雄宝殿前抬头找屋脊端部的鸱吻，再选一株有保护牌的古树观察。帝王树、石鱼等名称和故事可以帮助理解地方记忆，但“灵验”、龙宫或帝王预兆不是可验证的历史证明。

10月初不保证银杏已黄；二乔玉兰、戒台丁香主要是春季花景，不是这次目标。观音洞、塔院等支线是否开放另问，不强行寻访。

  1. 画三个时间：寺院源流 / 眼前建筑的说明年代 / 古树保护牌树龄，不知道就留空。
  2. 找一个屋顶细节：从台阶下看鸱吻、瓦色与轮廓，写一句它怎样让殿堂“显得大”；不用进封闭区。
  3. 读一个故事：帝王树或石鱼故事标成“地方传说”，再找它与可见实物的连接。
  4. 对照一段书：朱自清当年写竹、殿、屋顶、泉声。选你今天确实看到/听到的一项，写“相同 / 不同 / 今天无法核对”。

05 / 今晚20分钟就能开始

不是书单：点开对应文字就能读

第一篇 · 朱自清《潭柘寺戒坛寺》

作品原文 · 约10–15分钟

先读这一篇。它不是景点广告：出发的缘由、路途的疲倦、寺院空间、松与屋顶细节，还有作者不掩饰的感受，都能成为自己的观察方法。作品作于1934年，所记路线、接待与物件状态不能直接搬到今天。

阅读题：圈出一个你也想看见的细节，再圈出一个今天不能照做的动作。明天不用“赞同作者”，只要有自己的现场证据。

第二篇 · 《帝京景物略》“潭柘寺”条

明代地方风物记 · 选读约5–10分钟

这是比近代游记更早的一层观看记录。先看开头的寺名和旧谚，再找文中屋脊、树、碑与传说。古书中的神异叙述按当时的信仰与文学来读；旧里程和险径不是现代导航。旅游记忆本身，也有历史。

阅读题：各选一条“现场可能能核对的物件”和“必须保留为传说的叙述”，不要把古书记载一概升级为考古结论。
