# 城市探索任务表 · 三城阅读版 v1.2

这是独立的新页面，不是原抽签机的改版。发布位置为原仓库 `city-quests/` 子目录；原首页与个人数据库保留。两页的离线程序只管理各自资源，不相互清空缓存。

## 怎么用

1. 在此目录运行 `pwsh -File .\启动本地预览.ps1`，打开 http://127.0.0.1:8877/ 。电脑上的这个地址不能直接发给手机。
2. 悬赏板上按作品、主题、区域和星级挑任务，展开后接取。也能选“领一份今日悬赏”，它会参考当前筛选和出发条件，并避开上次随机任务、已完成和暂缓任务。
3. 卡片或详情页点一下“完成地点”就算完成，不必接取、勾完清单或写手记。点“撤销完成”回到进行中，清单和手记不变；完成后也可以继续补清单与手记。已完成地点不参与随机悬赏。“我的任务”收拢当前城市进行中、已完成和有手记/勾选的地点。
4. 地图上的圆点是地点或街区参考点，不是观众入口导航。默认只显示参考点；点击“加载联网底图”才连接OpenStreetMap。手机先切到“探索地图”。若地图服务不可达，任务和手记不受影响。
5. “备份与恢复”导出JSON文件。清空只影响本页；恢复校验后会确认完整替换。换设备、换网址或清理浏览器之前一定导出，不会自动同步到GitHub。

## 星级不是景区评级

- 三星：一个短途观察切口，适合先迈出一步。
- 四星：半日左右的专题比较，可能包含多个材料或空间。
- 五星：需要预约、远郊接驳或整日安排的专程探索。

它是本任务表的编辑分级，不是官方景区A等级，不是好坏排名，也不保证高星比低星更有趣。现在已有北京、苏州、秦皇岛，尚未覆盖全国；`province`、`city` 与城市配置可继续扩展。三星指任务切口较轻，不保证从所有出发点都能短途抵达。

## 三座城市怎样选

顶部“切换城市”同时改变悬赏板、地图参考点、区域筛选、出发点和资料入口；记住你上次选择的城市。每座城分别显示完成数，另有三城合计。清单与手记按稳定地点ID保存，切城不会清空进度。备份包含三城全部记录，而不只当前城市。

- 北京：保留原有30条详篇，从对外经济贸易大学校门估计往返。
- 苏州：16条详篇，从地铁**文昌路站**估计往返，按用户“文昌站”理解；若不是这个站，需要重新估计单程时间。
- 秦皇岛：6条简篇，住宿地未知，只估现场时间；时间筛选不能保证含往返赶得上，必须自行另加市内交通、排队与缓冲。金额不含赴秦皇岛车票、住宿、餐饮或打车。

苏州线索：浒墅关蚕里、苏博西馆、枫桥铁铃关、山塘西段、阊门西中市、艺圃、环秀山庄、沧浪亭、可园、文庙碑刻、耦园、丝绸博物馆、评弹馆、昆曲馆、桃花坞、甪直。每条含引子、问题、4步可选清单、2条文化阅读、路线与环境；小园任务和长距离交通分开估算。

秦皇岛线索：玻璃博物馆、西港花园、山海关中国长城博物馆新馆、老龙头、孟姜女庙、北戴河秦行宫遗址博物馆。每条有3步可选清单与一条阅读线索。新长城博物馆在**博物馆路1号**，不要误导航到第一关脚下旧馆。秦行宫遗址馆也不是秦皇求仙入海处。

## 资料怎样读

任务库共52条、202个可选清单步骤。先从区情沿革、地方志地情文章/索引、地方政府规划、公报及文物部门材料形成线索，再用馆方资料核对，最后把文学与艺术作品作为观察入口。原书索引不等于已全文通读；未核实的页码、精确年代、展品和演出不填写为确定事实。

每张任务包括引子、问题、可选清单、阅读关系、出处、环境、接待和费用。历史小说、传说、作品意象与史实分开说明，不抄录版权全文。资料整理日期是2026-10-01；馆方接待、票价和公交班次不能当成永远有效的承诺。

清单上方“先读再去”可直达首项阅读；“查看阅读材料”跳到本页文化线索，不会勾选清单或完成任务。巴金《随想录》选《小狗包弟》，直接链接中国作家网公开原文。阅读按钮区分原文、原文节选、导读、地点资料；导读和场馆说明不冒充整本书。26项材料有专配入口，其余明确提供相关地点资料，并注明不是作品全文。

5份古典文字可展开页内读：《枫桥夜泊》《武丘寺路》《长相思·山一程》为全诗/全词，《沧浪亭记》与《论语·微子》为明确标注的节选。缓存后可离线；本页原创观察提示也可离线。现代作品不镜像全文，外站文章仍需联网，能否打开受外站和网络影响。外链不发送手记或任务进度。

北京与苏州单程包含步行、等车和换乘；含往返时间 = 现场时间 + 单程×2 + 15分钟缓冲。秦皇岛的 `travel:null` 明确表示未知，绝不是零分钟；卡片显示“仅现场”。筛选用各自区间上限；不能把远郊交通当成市区地铁频率。宿舍至校门/家至车站、长时间用餐另加。预算为普通成人门票参考或保守占位估计加公共交通机动预留，**不是已核实报价**，不含餐饮、购书、打车、住宿、跨城车票与另收费项目，学生优惠需确认。时间、预算和精力是编辑估计，不是实时导航。

“出发时段”仅作适宜时段筛选，不计算每个场馆的精确抵达时刻。当天余票、末班车、开放展厅仍要自己确认。天气由你手动选择，程序不联网拉取天气、不定位你。

当前特别提醒：大钟寺公告继续闭馆至2026-10-30，计划10月31日恢复（临出发再确认）；鲁迅旧居从10月8日起暂停开放，博物馆其他开放区域不等于全部关闭。普通周一闭馆按保守规则筛掉，未取得明确假日开放信息的不自动豁免。团河行宫的旧旅游索引与新开放资料冲突，因此要求复核而不承诺常年接待。

| quest-data.js | 城市配置、引子、星级、区域、参考点与各城资料入口 |
| reading-resources.js | 按任务ID与阅读序号配原文/导读入口、古典页内文字和原创阅读提示 |
| manifest.webmanifest / service-worker.js | 独立安装身份和离线包 |
| vendor | 地图与坐标转换组件，以及授权文本 |
| 验收报告.md | 本次实际检查与仍未实测的边界 |

新增任务必须使用稳定不重复的 `id`（北京 `bjc_`、苏州 `sz_`、秦皇岛 `qhd_`），正文有 `culture.sources`、可选清单、现场区间、预算、环境和预约信息。北京在 `QUEST_META` 配元信息，新城直接在任务对象里配 `region`、`stars`、`reference`。有明确出发点再写 `travel:[下限,上限]`，未知则设 `null`，不要填 `[0,0]`。不要改旧ID或任意调整清单顺序，它们关联用户进度；重大改清单需做迁移。新城市要加 `CITY_CONFIG`、`REGION_LABELS`、`RESEARCH_PORTALS`、页面选项、数据加载和离线文件清单，并更新检查脚本的数量与城市坐标范围。

改任务正文后更新 `checkedAt`；本版离线缓存为 `v3`，下次更改需递增。缓存更新只删本页同作用域旧资源缓存，不删除本地进度。静态资源用 `./` 相对路径，支持GitHub Pages仓库子路径。不要借用原抽签机的IndexedDB数据库、存储键或缓存名。更新后联网打开，等待新版离线包建立，再刷新/重开；确认页脚版本为三城阅读版v1.2再离线出门。

新增阅读入口：在 `reading-resources.js` 按 `任务ID:阅读序号` 添加对象，`expectedTitle` 必须与对应 `culture.reading` 标题一致；`links` 记录HTTPS网址、来源、按钮文字和 `kind`。未专配时只返回已核对的地点资料，不能写成原书原文。`inline` 只能放明确可使用的古典原文或获授权材料，并区分全文/节选、标作者与出处；不要复制现代译文或版权全文。标题/序号不一致时会退回资料入口，检查脚本会报错，需修正映射。更换外链前打开页面确认它确实含所标注的内容。

本页存储键：`city-exploration-quests:state:v1`。浏览器存储异常时会提示仅保存在内存，应立即导出；不宣称自动跨设备同步或永不丢失。恢复不会运行备份里的代码；只接受已知任务ID、合法状态、布尔清单及最多6000字手记。

三城版继续使用v1备份封装，能读旧北京版备份；新规则允许 `done` 且清单未全勾。反向把三城备份导回旧北京程序会失败（新ID/旧完成规则），应始终用本版恢复。完成时保留 `completedAt`；撤销置空，其他字段不清。备份不含地图瓦片或外部资料原书。

## 独立部署与安装

本次按用户要求复用 `dcsdsg/life-explore-lottery-pwa`，本页位于 `city-quests/`，原抽签机仍在首页。Pages沿用main分支根目录；推送后等Pages构建完成，再打开 `https://dcsdsg.github.io/life-explore-lottery-pwa/city-quests/`。如果以后换新仓库，可以仅复制本目录的站点文件到新仓库根目录；先导出个人记录，再在新网址恢复。

HTTPS正式网址可安装；iPhone/iPad在Safari里“分享→添加到主屏幕”，Android/桌面浏览器用安装菜单。首次联网打开会缓存任务与本地资源，之后任务正文、清单、手记可离线使用；外链和底图必须联网。恢复页面时新版本缓存不会清除手记。

完整站点是静态HTML/CSS/JS，没有后端、会员校验或模型API调用，运行不依赖Codex额度。当地浏览器/PWA占用设备的存储空间，并不是上传到GitHub的个人数据库。

## 地图约定与授权

Leaflet 1.9.4 使用BSD-2-Clause；coordtransform使用MIT。授权文件在vendor目录。官方旅游网页的BD-09参考点经近似转换至WGS84，一些点来自公开坐标或地址附近的人工参考，并在任务内单独说明。旧帝王庙旅游页的点位与实际地址明显不符，未采用。地图精度不支持直接导航到门口。

OpenStreetMap仅在用户主动加载后按当前可见范围显示底图，遵守[瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)，使用标准HTTPS地址、保留浏览器Referer与可见署名、依赖正常HTTP缓存；不预取、不打包离线瓦片。可在app.js的地图配置处换成许可适合的提供商。没有运行或内置Nominatim地址搜索服务。联网地图会暴露当前视野瓦片请求，不发送手记与进度。

## 重新检查

当前电脑可以运行 `node scripts/check.cjs` 检查内容结构和出行规则。浏览器验收用本机已有Playwright和独立测试存储，不依赖真实用户数据。请在新部署后用自己手机完成一次Safari/Android安装和飞行模式复开；桌面仿真不能替代真机验收。
