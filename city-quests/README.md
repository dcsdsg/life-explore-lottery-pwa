# 城市探索任务表

三城版v1.1：北京30条、苏州16条详篇，秦皇岛6条简篇。共52个有引子、有可选清单、有出处的文化探索任务，支持三星至五星、城市地图、一键完成/撤销、本地进度、手记、备份恢复和PWA离线正文。

这是仓库 `city-quests/` 下的独立新页面，不替换原“生活探索抽签机”首页。三城之外还未覆盖全国；本地旧北京第一辑打包文件保留，不上传用户备份或预览日志。

正式入口：[城市探索任务表](https://dcsdsg.github.io/life-explore-lottery-pwa/city-quests/)。发布由原仓库main分支的GitHub Pages构建完成，推送后需等构建成功。

本地打开：在此目录运行 `pwsh -File .\启动本地预览.ps1`，访问 http://127.0.0.1:8877/ 。

可直接用 `?city=suzhou` 或 `?city=qinhuangdao` 打开某城。苏州从文昌路站估算往返；秦皇岛住宿地未设定，卡片只写现场时间，不含往返与跨城旅行费用。

详细使用、来源约定、维护与部署：[维护说明](./维护说明.md)。实际检查及真机未实测边界：[验收报告](./验收报告.md)。

静态站点，无账号、会员、模型API和后端数据库。任务与手记可离线；外链与地图底图需联网。定期导出JSON保管本地数据。
